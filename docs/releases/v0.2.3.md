# onspot 0.2.3

A release focused on phone performance, readable text sizes, and fixes found by using the app on a
real device.

## Highlights

- **120 fps on the phone.** Removed the SVG noise textures and fixed backgrounds that repainted on
  every scroll frame, kept the feedback sheet laid out while it is closed, and moved sheet motion to
  transforms. Slow drags, swipes, pull-up and Settings scrolling now hold 119–120 fps on a Galaxy
  S24 FE.
- **Live text-size preview.** Settings → Text size opens the real Practice screen, so you can tap a
  part (prompt, transcript, explanation, feedback) and adjust it while seeing the actual take.
  Sizes are stored per layout and per take length, and migrate the old text-size setting.
- **A better phone bar.** Two rows on phones: the prompt on top, then navigation, New prompt, Takes,
  Feedback, Session and the main action. Swipe up on the bar to pull Feedback open; the stats sheet
  can be put away with a tap or pinned in place.
- **One playback speed button.** Tap to cycle 0.75× → 1× → 1.25×; arrow keys and the wheel step
  without wrapping.
- **Per-section text size.** Prompt, “You said”, “Did you mean to say?”, explanation, translation
  and feedback each have their own scale from 85% to 160%.
- **Word meanings stay aligned.** Meanings are now keyed by word number, so a skipped word no
  longer shifts every later meaning.
- **Smaller fixes.** The language-of-instruction list opens as a capped portal and closes on a
  pick; Insights rows no longer overflow on phones; the word pop-up hides when its card is buried;
  README shows light mode first.

## First run

1. **Settings → Language data → Download.** French needs about 363 MB, once. It stays cached.
2. **Settings → LLM.** Paste a [Groq](https://console.groq.com) key (free tier is enough to try it)
   or point onspot at a local OpenAI-compatible server, then press **Test connection**.
3. Allow the **microphone**.
4. Pick a prompt and start talking.

## Known issues

- **French only.** Japanese is in development and is hidden in production builds until it passes a
  human listening test and transcript review.
- **The installers are not code-signed yet.** On macOS, you may need to allow the app in
  **System Settings → Privacy & Security**. On Windows, SmartScreen may ask you to confirm. On
  Android, you may need to allow installs from your browser or file manager.
- **Recording stops at 60 seconds.** Longer takes are on the roadmap.
- **No iOS build.** Desktop, web and Android are available today.
- **Windows and macOS builds are produced by CI and have not had a full hands-on pass** by the
  maintainer, who develops on Linux and Android. Please report anything that looks wrong.
- **The GitHub Pages demo cannot send the COOP/COEP headers** that local speech needs. Use the
  desktop or Android build for local speech; the Pages build is not the recommended way to try it.

# onspot 0.2.1

Installers for Intel Macs, ARM Linux and ARM Windows, an automatic model choice, and a thin title
bar on desktop.

## Highlights

- **More installers.** Intel Mac `.dmg`; Linux ARM64 `.deb`, `.rpm`, `.AppImage` and Flatpak;
  Windows ARM64 `.exe` and `.msi`; and the Android APK.
- **Automatic model choice.** Settings → LLM → Model now defaults to Automatic: each request goes
  to the most accurate model that handles your languages and still has room in its rate limits.
  Picking a model yourself pins it. This replaces "When a model is busy".
- **Show or hide the changes.** "Did you mean to say?" has a Show changes / Hide changes link:
  your words struck through before each fix, or the clean corrected text.
- **Hear a selection.** Select some words and their meaning gets a speaker button that reads them
  aloud in the language you are studying. The selection stays together until you put it away.
- **A thin title bar** on Windows and Linux that follows light and dark mode. macOS keeps its own
  window buttons.
- **The AppImage uses X11** when it is available, which fixes slow resizing and a stuck window size
  after maximising under Wayland.
- **The feedback bookmark is readable in dark mode.**

## Known issues

- **French only.**
- **The installers are not code-signed.** On macOS, you may need to allow the app in
  **System Settings → Privacy & Security**. On Windows, SmartScreen may ask you to confirm. On
  Android, you may need to allow installs from your browser or file manager.
- **Recording stops at 60 seconds.**
- **No iOS build.**
- **Windows and macOS builds are produced by CI and have not had a full hands-on pass.** Please
  report anything that looks wrong.

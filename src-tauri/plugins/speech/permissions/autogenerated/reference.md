## Default Permission

Everything onspot's speech UI needs: manage the downloaded model and transcribe.

#### This default permission set includes the following:

- `allow-model-status`
- `allow-download-model`
- `allow-cancel-download`
- `allow-delete-model`
- `allow-load-model`
- `allow-transcribe`
- `allow-release`
